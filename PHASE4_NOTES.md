# Phase 4 analysis

This phase does not add another forecasting model. It summarizes the existing
real-data walk-forward experiment.

Questions:
1. Does LSTM performance differ across commodities?
2. Does LSTM beat the simple momentum benchmark consistently?
3. Are the patterns different between energy and precious metals?
4. How sensitive are WTI conclusions to the 2020 negative-price episode?
5. Does higher directional forecast accuracy translate into higher Sharpe?

Run:

    python experiments/phase4_analysis.py

The script expects `results/lstm_walk_forward.csv`, generated by the real-data
LSTM experiment. Outputs are written to `results/phase4/`.

Do not interpret a single strong window as evidence that a model is generally
profitable. The emphasis is on cross-window stability and comparison with the
simple benchmark.
